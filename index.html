操作手册
建筑编辑
  • 左侧建筑列表可拖拽到地图放置建筑。
  • 手机端可先点建筑，再点地图完成放置。
  • 右键建筑可旋转。
  • 按住左键拖动建筑可移动；拖到左侧工具栏区域可删除。
  • 选中建筑后可用 Ctrl/Cmd + C 复制，Ctrl/Cmd + V 粘贴到附近可容纳位置。
  • 按 Ctrl/Cmd + A 可选中地图上的全部建筑。
  • 选中建筑后，按 Backspace / Delete 可删除。
工具条操作
  • 顶部工具条支持导入、导出、清空和打开说明。
  • 支持导出图片：地图开启时导出100x100区域，地图关闭时导出整个地图，并在顶部留白显示水印信息。
  • 地图工具支持撤销/重做、地图底色开关、网格线黑白切换、群转90°、镜像和建筑统计。
  • 撤销快捷键：Ctrl/Cmd + Z；重做快捷键：Ctrl/Cmd + Y（macOS 也支持 Cmd + Shift + Z）。
地图导航
  • Windows: Ctrl + 鼠标滚轮缩放。
  • macOS: 触控板捏合缩放（或 Meta/Ctrl + 滚轮）。
  • W / A / S / D 键移动地图视口，Shift + WASD 为快速移动。
框选与批量操作
  • 在地图空白处左键拖拽可框选多个建筑。
  • 按住 Ctrl（Windows）/ Command（macOS）点击或框选，可在当前选择基础上追加多选；点击已选中的建筑可取消选中。
  • 拖动已选中的任意一个建筑，可整体批量移动。
  • 多选后按 Backspace / Delete 可批量删除。
  • 点击群转90°可按选中集群中心顺时针旋转，若越界或重叠会自动取消。
Buff 与数据
  • 点击建筑后，右侧显示该建筑 Buff 明细。
  • 点击右侧某条 Buff，可在地图高亮其来源建筑。
  • 支持导入/导出布局，以及加载内置布局。
  • 开启地图底色后，移动/粘贴建筑会受地图约束：仅可在 100x100 范围内且只能放在白色格子。
  • 会自动缓存地图布局、缩放系数和滚动位置。
