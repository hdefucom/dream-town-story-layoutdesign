操作手册
建筑编辑
  • 左侧建筑列表可拖拽到地图放置建筑。
  • 右键建筑可旋转。
  • 按住左键拖动建筑可移动；拖到左侧工具栏区域可删除。
  • 选中建筑后，按 Backspace / Delete 可删除。
地图导航
  • Windows: Ctrl + 鼠标滚轮缩放。
  • macOS: 触控板捏合缩放（或 Meta/Ctrl + 滚轮）。
  • W / A / S / D 键移动地图视口，Shift + WASD 为快速移动。
框选与批量操作
  • 在地图空白处左键拖拽可框选多个建筑。
  • 拖动已选中的任意一个建筑，可整体批量移动。
  • 多选后按 Backspace / Delete 可批量删除。
Buff 与数据
  • 点击建筑后，右侧显示该建筑 Buff 明细。
  • 点击右侧某条 Buff，可在地图高亮其来源建筑。
  • 支持导入/导出布局，以及加载内置布局。
  • 会自动缓存地图布局、缩放系数和滚动位置。
