# 箱庭都市 布局设计工具

English Version: [README_EN.md](README_EN.md)

用于《箱庭都市》手游的地图布局规划工具，支持建筑拖拽放置、Buff 计算、道路绘制、布局导入导出等功能。纯前端实现，无需后端服务，但需要通过本地 HTTP 服务访问（否则浏览器会拦截 JSON 元数据读取）。

> 声明：本项目代码与文档 100% 由 AI 开发。
>
> 使用 GitHub Copilot 辅助开发。

## 快速启动

请在项目根目录启动本地 HTTP 服务后访问：

```bash
python3 -m http.server 8000
```

然后在浏览器打开：`http://localhost:8000/`

## 功能列表

### 建筑编辑
- 左侧建筑列表支持**拖拽到地图**放置；移动端可先点建筑再点地图完成放置
- **右键建筑**可旋转（桌面端）；移动端通过底部操作栏旋转
- **左键拖动建筑**可移动，拖到左侧工具栏区域可删除
- 选中建筑后支持 **Ctrl/Cmd + C 复制、Ctrl/Cmd + V 粘贴**到附近可容纳位置
- **Ctrl/Cmd + A** 选中地图上全部建筑
- 选中建筑后按 **Backspace / Delete** 删除
- 支持**撤销/重做**（Ctrl/Cmd + Z / Y，macOS 也支持 Cmd + Shift + Z）

### 框选与批量操作
- 在地图空白处左键拖拽可**框选**多个建筑
- 按住 Ctrl/Cmd 点击或框选可**追加多选**；再次点击已选中建筑可取消选中
- 多选后拖动任意一个建筑可**整体批量移动**
- 多选后支持批量删除、**群转 90°**（按选中集群中心顺时针旋转，越界/重叠自动取消）、**镜像**翻转

### Buff 与地价计算
- 点击建筑后，右侧面板显示该建筑**实时 Buff 明细**（专业街、雕像、奖杯、景观等）
- **Buff 来源列表**：点击某条 Buff 可在地图上高亮对应来源建筑
- **地价数值加成建筑列表**：展示所有对当前建筑有范围地价加成的邻近建筑；点击可定位到地图并触发临时高亮和范围特效
- 建筑详细信息展示：基础地价、Buff 数量、总地价加成（%）、总商品加成（%）、范围地价加成数值；有 `scope` 字段的建筑展示"范围：X 格，+Y"
- 地价计算公式：`基础地价 × 总地价加成% / 100 + 范围地价加成`

### Scope 范围特效
- 选中有 `scope` 字段的建筑时，地图上以**蓝色脉冲格子**可视化显示其影响范围（菱形）
- 点击地价加成列表中的建筑时，也会触发临时范围特效（约 2 秒后自动消失）

### 道路系统
- 开启**道路绘制模式**，在地图上涂色绘制道路格子
- 支持**道路验证**：自动检测建筑是否有道路连通，对未连通的建筑显示警告角标
- 可一键将路径上的格子**转化为道路**

### 地图视图控制
- **地图底色**开关：显示 100×100 游戏地图区域底图；开启后建筑只能放置在白色格子内
- **网格线**开关（黑/白切换）
- **分区线**开关
- **高亮相同**：选中建筑后高亮地图上所有同类建筑
- **限定建筑**筛选：左侧建筑列表可过滤限定/非限定建筑
- 同类建筑切换按钮（← / →）：快速在同类建筑间切换选中

### 地图导航
- 鼠标滚轮 / 触控板捏合**缩放**地图（Windows: Ctrl + 滚轮；macOS: 捏合或 Ctrl/Meta + 滚轮）
- **W / A / S / D** 键移动视口，**Shift + WASD** 快速移动
- 实时坐标显示（左下角 HUD）

### 导入 / 导出
- **导出布局**（JSON）：包含所有建筑位置、道路数据、地图开关状态
- **导入布局**：还原建筑、道路及地图开关状态；支持内置预设布局一键加载
- **导出图片**：地图底色开启时导出 100×100 区域，关闭时导出整个地图；顶部自动添加水印/统计信息

### 数据查询面板
- **建筑数据**：建筑属性速查
- **专业街**：Buff 配置一览
- **职业勋章**：勋章数据
- **商店**：商店信息
- **交通 / 宠物**：交通及宠物数据
- **排名奖励**：排名区间奖励参考
- **建筑统计**：统计当前地图各类建筑数量及总量

### 其他
- 自动缓存布局、缩放系数、滚动位置（本地存储）
- 移动端适配：顶部导航栏、侧边面板收起/展开、底部操作按钮

## 已知限制

- 已支持雕像、奖杯、景观类加成，但目前仅部分维护了对应元数据，个别建筑可能出现缺失或计算不完整
